# Safety Pomodoro

Pomodoro-таймер для специалистов по охране труда с режимами фокуса и
медитации, сезонным оформлением, фоновыми звуками и локальным сохранением
настроек.

## Возможности

- автоматическая тема по времени года и ручной выбор сезона;
- рабочий таймер и отдельный таймер медитации;
- задачи, настройки и статистика в `localStorage`;
- очистка сохранённых данных из интерфейса;
- звуки природы и процедурные Brown noise, дождь и тихий drone;
- русский и английский интерфейс;
- адаптивная вёрстка и поддержка `prefers-reduced-motion`.

## Локальный запуск

```bash
npm install
npm run build
npm run check
npm start
```

Откройте `http://localhost:8000`.

GitHub Pages использует готовые `app.js` и `styles.css`, поэтому после
изменения `app.jsx` необходимо выполнить `npm run build` и закоммитить
обновлённые артефакты.
